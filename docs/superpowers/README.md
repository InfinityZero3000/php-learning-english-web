# Design and implementation archive

`specs/` lưu quyết định thiết kế và `plans/` lưu trình tự triển khai tại thời
điểm chúng được viết. Nhiều plan đã được thực hiện qua các commit khác nhưng
checkbox lịch sử không được cập nhật, vì vậy không dùng số checkbox trống làm
backlog.

Xem [`../CURRENT_STATUS.md`](../CURRENT_STATUS.md) để biết trạng thái hiện hành,
phần còn thiếu và kết quả xác minh mới nhất. Khi code mâu thuẫn với mô tả trạng
thái cũ, ưu tiên code + test, sau đó cập nhật `CURRENT_STATUS.md`.
